Master Calendar — User Guide

Version 2026-11-13. See 8. What's new.

This sheet holds the school calendar: one tab per school year (for example 2026.2027), one row per school day, with each day's schedule, periods and class times. The assign-sheet and course-manager workbooks read their dates and class times from it, so a fix here reaches them the next time they pull from the Master.

Everything here is on the Master Calendar menu at the top of the sheet, next to Help. If you don't see the menu, reload the page and wait a few seconds. This guide is always at Master Calendar › User guide. It opens in a panel on the right, so you can follow the steps while you work in the sheet. Close it with the ✕ at its top.

Does this change anything outside the sheet? No. The menu only reads the school's public calendars. It never changes Canvas, the calendars, or the other workbooks. Build year tab only adds a new tab, and never changes a year tab that already exists.

1. Setup: the calendar links

Master Calendar › Setup… opens the Setup panel on the right. The menu reads two of the school's public Google calendars:

  • Bell Schedule with Periods: each day's schedule title (for example "E3 Schedule (3,4,1,2)") and a timed event for every period. The schedule codes, periods and times come from here.
  • Faculty Calendar: exams, open houses, Mid-Quarter and other events. It's used for the exam days and for the suggested Data Drills notes.
  1. Part 1. Calendar links shows ✓ or ⚠ for each link: saved or not yet. Test links downloads both calendars and shows how many events each has and their first and last dates, or what went wrong.
  2. Part 2. Set or change the links: paste each calendar's public .ics link (it starts with https:// and ends in .ics) and click Save. It saves only if both look right, then tests them. Leave a box as it is to keep the saved link.

The links are saved with the sheet's script, not on a tab. They're public addresses, not passwords. Where to find them: in Google Calendar, open the calendar's Settings and look for Public address in iCal format.

The first time you use the menu, Google asks you to allow the script to see and edit this spreadsheet only, show pop-ups and the side panel, and connect to an external service (to download the calendars).

3. Build a new year tab

Master Calendar › Build year tab from calendars…

Use it once a year, when the school has put the new year into the Bell Schedule with Periods calendar (usually by August). If the PDF calendar comes out first, you can start the tab by hand as before and use Preview a year (section 4) to check it once the calendar has the year.

  1. Type the year, for example 2027.2028: four digits, a dot, four digits. If a tab with that name already exists, nothing is changed.
  2. Wait while it downloads the two calendars (a message shows in the bottom-right corner). The new tab appears in front of the other year tabs.
  3. A pop-up says how many school days it wrote, from the first day to the last exam day, and how many days to review.

What it fills in:

  • Rows: every weekday from the first day of school to the last exam day. Long breaks are left out; a holiday next to a break counts as part of the break.
  • Q and Wk: a new quarter starts after a gap of more than a week; weeks run Monday to Friday.
  • Schedule: the code, worked out from each day's title in the Bell Schedule calendar. Exam days become EX1, EX2… from the Faculty Calendar.
  • Day, Periods, JSON: the same formulas as the other year tabs.
  • Data Drills: grey italic suggestions: First Day of School, No Chapel, holidays, special schedules, and Faculty Calendar events such as open houses, Mid-Quarter (MQ), exams and awards. Keep, change or delete them; you can change the text to normal black when you've checked it. Expect a few extras, such as open houses you don't need.
  • AP Schedule: left blank. AP exams aren't in either calendar.

Days to review

Rows to check are yellow, with the reason in a note on the Schedule cell (point at the cell's corner to read it). The reasons:

Note saysWhat to do
5 periods in the calendar (expected 6)The calendar is missing a period on that day. Usually the code is still right; check the PDF.
special schedule "…": code guessedA special day (Christmas, Easter…). Check the code against the PDF.
no schedule code for "…"The title didn't match any code (for example "No US classes"). The code is ?: type the right one.
code … is not in *Data Sched-Per*A new code. Add it (section 5), or change the day to a code you have.
*Data Sched-Per* says …The calendar lists the periods in a different order from your list for that code. Check which is right.
code … has no times in *schedule*The JSON column will be empty that day. Add the code's times to *schedule* (section 5).

When you're done, clear the yellow and the notes if you like. Then, in each assign-sheet and course-manager workbook, change the school year in Config to the new tab's name and pull from the Master.

4. Preview a year (Test tab)

Master Calendar › Preview a year (Test tab)…

Builds the same rows in a tab called Test, without touching any year tab. Use it to compare a year tab you made by hand with the calendar, or to look at a year before you build it. If the Test tab already has data, it asks before replacing it.

The Test tab differs from a year tab in three ways:

  • Periods and JSON are what the calendar says, not formulas, so you see the calendar's own times.
  • J Review gives the reason for each yellow row (the same reasons as in section 3).
  • K compares each day with the year tab of the same name, if there is one: blank when they match, otherwise what the year tab has (for example Schedule: Fr · Periods: 7,8,M/L,5,6). not in the year tab means the day is missing there. K compares codes and periods, not times.

The pop-up also lists days that are in the year tab but not in the calendar (for example Graduation on a Saturday).

5. Fix a day, or add a schedule code

Fix a day

Change the code in column E. Periods (F) and times (I) update by themselves. Check that F shows the periods you expect and that I has a time for each class period. If F shows --- or I is empty ([]), the code is missing from a reference tab: see below.

Add a new schedule code

A code needs a row in both reference tabs. The spelling must match exactly, capitals included (CH and Ch are different codes).

  1. *Data Sched-Per*: one row. Column A the code, column B the periods in order, separated by commas, for example Ch-A,Ch-B,7,8,L,5,6. For a day with no classes, use - - -.
  2. *schedule*: one row per class period. Column A the code, B the period number, C the start time and D the end time, typed as numbers without a colon: 940 for 9:40, 1355 for 1:55. The order of the rows doesn't matter.
Times without a colon. If Sheets turns 1209 into 12:09, the JSON column gets a date instead of a time. Retype it as 1209; if it changes again, set the cell to Format › Number › Automatic first. And if you work out end times with a formula ("next start minus 5"), watch the hour: 5 minutes before 10:02 is 957, not 997.
