Assignment Sheet — User Guide

Version 2026-11-13. See 6. What's new and getting updates.

For teachers using a course Assignment sheet (Biology, Gastronomy, AI9, or a copy). Everything here is on the Canvas Tools menu at the top of the sheet, next to Help. If you don't see the menu, reload the page and wait a few seconds. This guide is always at Canvas Tools › ❓ User guide. It opens in a panel on the right, so you can follow the steps while you work in the sheet. Close it with the ✕ at its top.

The sheet does two jobs:

  • Keeps your quarter schedules (Q1–Q4 tabs) in step with the school's master calendar. The Q tabs come with the workbook; the script refreshes the data they read.
  • Sends things to Canvas: calendar events, announcements, and assignment dates.
Which tools change Canvas? Only three: Post selected calendarEvents rows to Canvas, Send changed dates to Canvas, and Remove section/student dates on selected rows. Everything else only reads Canvas or works inside the sheet. The tools that change Canvas always show you what they will do and ask Yes/No before sending.

1. First-time setup

Do this once per sheet, per teacher.

Your Canvas token

The sheet talks to Canvas using your own access token, a long password-like code that Canvas makes for you. It is saved to your Google account only: other people who can edit the sheet cannot see it, and it is never shown on the sheet.

  1. In Canvas, go to Account › Settings, scroll to Approved Integrations, and click + New Access Token. Give it a purpose (for example "Assignment sheet") and copy the token. Canvas only shows it once.
  2. In the sheet: Canvas Tools › ⚙️ Setup…. The Setup panel opens on the right.
  3. In part 2. Set or change your token, check the Canvas address: the start of the address bar when you are logged in to Canvas (for example https://yourschool.instructure.com). It's filled in from Config B2 if you haven't saved one yet. Paste the token and click Save.
  4. The panel tests the connection by itself. Part 1. Canvas connection should show ✓ Connected. and ✓ Token: saved with the date and the last 4 characters of your token, so you can tell which of your Canvas tokens it is.
  5. Part 3. Which course shows the course number from Config B4 and Canvas's name for it. If it's the wrong course, type the right number (or paste the course's Canvas address) and click Save course.

Open ⚙️ Setup… any time to check that everything is ready. To change the address or token later, use part 2 again; leave a box blank to keep what's saved. A token saved before 11/12/2026 shows without a date until you save a new one. If you ever think your token was exposed, delete it in Canvas (Account › Settings › Approved Integrations) and make a new one.

Google's permission screen

The first time you use any Canvas Tools item, Google asks you to authorize the script. It asks to:

  • see and edit this spreadsheet only (not your other files);
  • show menus and pop-up boxes in the sheet;
  • connect to an external service (Canvas).

Preview mode

Preview mode lets you try a tool safely. When it's ON, the Canvas tools do everything except actually send: they check your rows and write "Preview mode OK" where a link or status would go. Nothing changes in Canvas. When you open the sheet, a message at the bottom right says whether it's ON or OFF.

  • Canvas Tools › ⚙️ Setup…, part 4. Preview mode, shows which mode you're in: green ON: safe or orange OFF: changes WILL be sent.
  • Click Turn preview mode off… (it asks first) or Turn preview mode on. While preview mode is OFF, Save course also asks first.
  • Preview mode is a setting for the whole sheet, not per teacher. If you share a sheet, check the status before you post.
  • Every "Post", "Send", or "Remove" confirmation box also says whether preview mode is on.

A good habit when trying something new: turn preview mode ON, run the tool, check the results, then turn it OFF and run it for real.

2. Schedule tools

🔄 Update schedule from Master

Pulls the latest school days, schedules, holidays, and drills from the master calendar so your Q1–Q4 tabs show them. Run it when the master calendar changes. It does not create or redesign the Q tabs; it refreshes the data their formulas read.

  • Steps 1–5 show in the bottom-right corner as it runs; wait for Full Schedule Update Complete!
  • It rebuilds the helper tabs *scheduleLookup*, AssignmentMaster, and AssignmentLookupFinal, then nudges the formulas on each Q tab (cells A4 and B2) so they recalculate. Don't type in the helper tabs; your typing will be replaced.
  • Only the period pairs checked in Config E2:F5 are included.
  • Does not touch Canvas.

Afterward: on each Q tab, check columns A–E to make sure every period pair you want is filled in. You may need to unhide those columns first (right-click the column letters › Unhide columns).

F–GYours: lesson content, anything you like, including links.
HYours. For example, check off a row once its content is set up in Canvas.

🔗 Reset Master connection

Use this if the *simpleSchedule* tab shows #REF! or is empty, or after changing Config D3 or D5. It re-links *simpleSchedule* to the master calendar.

  • Afterward, look at *simpleSchedule* cell A1. If it shows #REF!, click the cell and choose Allow access.
  • Then run 🔄 Update schedule from Master.
  • Does not touch Canvas.

☑️ Toggle checkboxes

Select a block of checkboxes (on any tab) and run this: if they're all checked, it unchecks them; otherwise it checks them all. Handy for the calendarEvents and Assignment Dates tabs.

3. 📅 Calendar events and announcements

Canvas Tools › 📅 Calendar & announcements › Post selected calendarEvents rows to Canvas (also the drawn Post selected rows to Canvas button on the tab).

Posts rows of the calendarEvents tab to your course as all-day calendar events, announcements, or both. This changes Canvas (preview mode applies).

The tab

Row 2 is the header row; your rows start on row 3.

ColumnWhat it does
A Calendar ☐Check to make a calendar event.
B Announcement ☐Check to make an announcement.
C TitleRequired. Rows with no title are ignored.
D BodyThe text of the event or announcement.
E Calendar DateRequired if Calendar is checked.
F Delayed PostOptional: when the announcement should appear. Blank = right away.
G Replies? ☐Check to let students reply to the announcement.
HFilled in by the tool: View Event link (or status).
IFilled in by the tool: View Announcement link (or status).

Steps

  1. Fill in the rows and check Calendar and/or Announcement.
  2. Select the rows you want to post (click and drag down the row numbers, or any cells in those rows).
  3. Run the menu item or click the button.
  4. Read the confirmation (course number, how many events and announcements, preview mode on or off) and click Yes.

What you'll see

  • View Event / View Announcement in H or I: posted; click to open it in Canvas.
  • Preview mode OK: checked but not sent (preview mode was on).
  • Failed: …: that item didn't post; the pop-up says why.

Good to know

  • No duplicates: if H or I already has a link (or "View …" text), that part is skipped. To post it again, clear that cell first.
  • If a row has Calendar checked but no date, nothing is sent until you fix it.
  • It only runs on the calendarEvents tab.
  • Editing a row after posting does not update Canvas. Edit the event or announcement in Canvas directly.

4. 📝 Assignment dates

Change open, due, and lock dates for many assignments at once, in a sheet instead of one at a time in Canvas. Uses the Assignment Dates tab.

Load assignment dates from Canvas

Canvas Tools › 📝 Assignment dates › Load assignment dates from Canvas

Fills the Assignment Dates tab with every assignment in the course (Config B4), earliest due date first (no due date at the bottom). Read-only: it does not change Canvas. Running it again replaces everything from row 2 down with fresh data from Canvas, so any unsent edits are lost.

Section dates (rows marked ↳)

If an assignment has different dates for some sections or students, each of those shows as its own row right under the assignment, with its name, type, and points cells (C–E) shaded gray:

  • ↳ Period 3: dates for that section.
  • ↳ Jane Doe, Sam Lee: dates for specific students (for example extra time). More than three show as "+ 2 more"; click the assignment's name to see them all in Canvas. Anyone who can open this sheet can see these names, so mind who it's shared with, and hide this column in screenshots.
  • ↳ Group: dates for a group.

The assignment's own row holds the "Everyone else" dates: everyone not on a ↳ row. You can edit and send both kinds of rows the same way.

A date in italics isn't set separately for that ↳ row: it just uses the assignment's date (hover to see a note). Leave it as is and it keeps following the assignment; change it and that row gets its own date. After sending a change to an assignment's own dates, load again before editing its ↳ rows, so the italic dates are up to date.

Add section dates

Canvas Tools › 📝 Assignment dates › Add section dates below selected assignment

  1. Click any cell in the assignment's row and run the menu item.
  2. A new gray row appears under the assignment (and any ↳ rows it already has). It starts with the assignment's dates, and its Update? box is already checked.
  3. In column C, pick the section from the dropdown. The list only shows sections that don't have their own dates for this assignment yet.
  4. Change the dates for that section, then run Send changed dates to Canvas.

Until it's sent, the row's Override ID says new. Loading again before you send throws the new row away. A date you leave blank where the assignment has one means "no date" for that section.

Add student dates

Canvas Tools › 📝 Assignment dates › Add student dates below selected assignment

Works like Add section dates, for students who need their own dates (for example extra time). One row per student:

  1. Click any cell in the assignment's row and run the menu item.
  2. Type how many students (or leave it blank for one). That many gray rows appear, each with the assignment's dates and Update? checked. Their Override ID says new students.
  3. On each row, pick a student from the dropdown in column C. It lists only students who don't already have their own dates for this assignment.
  4. Change the dates (each row can be different), then run Send changed dates to Canvas.

If the same student is picked on two rows, or already has their own dates for this assignment, nothing is sent and a pop-up says which row to fix. Canvas allows only one set of dates per student per assignment. Adding or removing a student on an existing ↳ row is done in Canvas for now.

Remove section or student dates

Canvas Tools › 📝 Assignment dates › Remove section/student dates on selected rows

Takes away a ↳ row's own dates in Canvas. Those students go back to the assignment's "Everyone else" dates.

  1. Select the ↳ rows to remove (click a cell in each; hold Ctrl, or ⌘ on a Mac, to pick several). The Update? boxes don't matter for this.
  2. Run the menu item.
  3. Read the confirmation (how many section, student, and group rows, and whether preview mode is on) and click Yes.

A removed row stays on the tab, grayed out and crossed out, until you load again. Sending skips it.

Only ↳ rows are removed. Assignment rows and rows hidden by a filter are left alone. A new row that hasn't been sent yet isn't in Canvas: just delete that row from the sheet. Removing a student row removes the dates for every student on that row.

Sorting

Canvas Tools › 📝 Assignment dates › Sort by selected column (keeps ↳ rows together)

Click any cell in the column you want to sort by (for example Due Date or Assignment Name), then run this. Assignments are sorted by their own row, earliest or A to Z first, with blanks at the bottom. Sorting by a date also sorts by its time. Each assignment's ↳ rows move with it and stay right below it. It only rearranges the tab; nothing goes to Canvas.

Use this instead of the sort in the filter arrows: those sort every row on its own, so ↳ rows end up away from their assignment. (Sending still works either way, but the tab is hard to read.) If the filter is hiding rows, show all rows first.

Editing dates

  • Date cells: double-click for a calendar, or type like 8/12/26. The cell rejects anything that isn't a date.
  • Time cells: type it, like 4:00 pm or 11:59 pm. (Google Sheets has no time picker.)
  • Every date needs a time, so nothing lands at midnight by accident.
  • To remove a date, clear both the date and the time.

Send changed dates to Canvas

Canvas Tools › 📝 Assignment dates › Send changed dates to Canvas

This changes Canvas (preview mode applies). Students see the new dates.

  1. Check Update? on the rows you changed.
  2. Run the menu item. It checks Canvas first and only sends the dates that are actually different.
  3. Read the confirmation (how many rows and dates will change, preview mode on or off) and click Yes.

Only the open, due, and lock dates are sent. Changing a name or points on this tab does nothing; change those in Canvas.

6. What's new and getting updates

Your copy of this sheet doesn't change when the template it came from is improved. The version at the top of this guide tells you which one you have. To see whether there's a newer one, open the template and look at the version in its guide.

What's new

  • 2026-11-13: New 📥 Bring over from my old copy…: in a fresh copy of the template, it brings your settings, Q-tab lessons, calendarEvents rows and your own tabs over from your old sheet (see Getting the newest version below). Google asks for permission again the first time, now including See all your Google Sheets spreadsheets: the sheet only reads the one old copy you paste, and never changes it.
  • 2026-11-12b: Dry run is now called preview mode (same setting, new name), matching Course Manager. Status cells say "Preview mode OK", and a message when the sheet opens says whether it's ON.
  • 2026-11-12: New ⚙️ Setup… panel replaces the ⚙️ Setup submenu: save your token (it shows the last 4 characters and the date saved), test the connection, check or change the course, and turn dry run on or off, all in one place.
  • 2026-11-10: Section and student dates on the Assignment Dates tab (rows marked ↳): load, edit, add, and remove them. Sort that tab by any column. Version label and this section added to the guide.
  • 2026-11-08: This guide opens in a panel on the right of the sheet.

Getting the newest version

You make a fresh copy of the template and bring your own work over. Your old sheet stays as it is, so nothing is lost.

  1. Open the template (the same link you used for your first copy) and make a copy.
  2. In the new copy, run 🔄 Update schedule from Master so the Q tabs have their dates. (If it complains about Config, fill in D3 and D5 first; see 1. First-time setup.)
  3. Open Canvas Tools › 📥 Bring over from my old copy…. A panel opens on the right.
    • Paste the link to your old sheet (the whole address from its address bar) and click Look at it. Check that the name it shows is your old sheet.
    • The plan has one line for each tab of your old sheet. Change a choice if you need to, then click Bring over.
  4. Read 4. What happened in the panel. It lists anything to redo by hand (charts, pivot tables and a few others), with how.
  5. Open ⚙️ Setup…, save your token, and check the course. A new copy needs your token again: it isn't carried over.
  6. Run 📝 Assignment dates › Load assignment dates from Canvas.
  7. Check preview mode: Canvas Tools › ⚙️ Setup…, part 4. A new copy may start with it ON.
  8. Rename the old sheet (for example "OLD Assignment sheet") so you don't use it by mistake. Keep it until you're sure everything came over.

If the Q tabs' dates still don't match after 🔄 Update schedule from Master, the school calendar has changed since your old sheet. Set those tabs to Skip, and copy your columns F onward by hand, checking the dates in column A as you go.
